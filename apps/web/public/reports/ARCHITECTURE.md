# FlowCore 구조와 적용 범위

React + TypeScript strict/Vite(8000), ASP.NET Core .NET 10 LTS(8001), EF Core/SQLite로 구성한 회사 브랜드 업무요청 샘플이다. S01 로그인, S02 현황, S03 목록, S04 상세, S05 단계형 등록·수정, S06 관리자 상태변경, S07 도움말·표준 자료실, S08 갤러리와 개인정보 안내를 포함한다.

브라우저는 개발 프록시 `/api`로 API를 호출한다. 서버는 쿠키 인증과 CSRF 검증 후 DTO를 검증하고 소유자/관리자 권한을 적용한다. 파일은 웹루트 밖에 보관하고 다운로드 때 다시 인가한다. UI의 버튼 노출은 보안 경계가 아니다. SQLite와 첨부파일은 서버 재시작 후에도 유지한다.

표준 정의는 `standards/catalog.json`, 적용 기록은 `standards/application-records.json`, 시험 절차는 `standards/tests.json`, 실제 실행 기록은 `evidence/index.json`이 소유한다. Excel/PPT/HTML/Help는 이 데이터를 읽는다. 기록의 `code_refs`는 상대경로와 심볼을 연결하고 원본 출처/페이지를 보존한다. 297행은 겹치는 관리행이며 단일 인증의 분모가 아니다.

신뢰 경계는 브라우저 입력, 인증 쿠키, API, DB, 첨부 저장소, 빌드 의존성, 문서 내보내기다. 주요 위협은 타 사용자 객체 접근, 관리자 API 우회, 위조 요청, 업로드 실행, XSS/SQL 인젝션, CSV 수식 주입, 비밀 노출이다. 권한·입력·CSRF·파일형식 검사와 실패 시험으로 경계를 확인한다. 악성코드 엔진, 운영 TLS 인프라, 외부 CI 실제 실행, AT/장애 당사자 평가는 별도 운영 인수 대상이다.

법령 적용 의무는 계약·기관·사업 조건에 따라 판단해야 한다. 이 회사 샘플은 정부 서비스 또는 의료기기이며 인증받았다는 주장을 하지 않는다. 공식 요구, 사내 채택안, 설계 선택, 수동 미검증을 원장 필드로 구분한다.
