# 접근성 구현·시험 범위

KWCAG 2.2 33개와 WCAG 2.2 A/AA 55개를 독립 ID로 관리한다. WCAG 4.1.1 Parsing은 WCAG2.2에서 제거됐고 KWCAG 마크업 오류 방지는 유지된다. 네이티브 HTML을 우선하고 ARIA는 필요한 상태/이름에만 사용한다.

키보드 과업, 건너뛰기, SPA 제목/초점, 대화상자 열기·닫기·초점복귀, 오류·도움말 연결, 텍스트 상태, 비밀번호 붙여넣기/자동완성, 검토 및 입력보존을 구현한다. 일반 문자4.5:1/큰 문자3:1/필수 비텍스트3:1과 WCAG 대상24px, 회사44~48px 목표를 구분한다.

실제 실행한 Playwright/axe 결과는 해당 URL·역할·상태와 브라우저에 한정한다. 320 CSS px 자동 뷰포트 검사는 실제 400% 브라우저 확대나 화면낭독기 음성 검사를 대체하지 않는다. 200% 텍스트 확대·400% 확대·문자간격·forced colors·색 제거·음성입력·모바일 AT·NVDA·당사자 평가 절차를 시험대장에 유지한다.

각 규칙 `MAN-<rule_id>`에는 대상 화면·절차·예상결과·환경·실제결과·판정·증빙 칸이 있다. 자동시험은 일부분을 확인하면 부분확인으로 연결하고 전체 조항 PASS로 승격하지 않는다. 필요한 수동시험이 미실행이거나 검토자/증빙이 없으면 종합 통과가 아니다.

첨부 이미지는 인라인 필수정보로 사용하지 않는다. 첨부 문서 자체의 접근성, 번역문구 부분언어, 모든 사용자 환경의 읽기순서/낭독 맥락은 수동 검토가 필요하다. 미디어·센서·단일문자 단축키 등 조건부 기능 도입 시 연결 조항을 재평가한다.
