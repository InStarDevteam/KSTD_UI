# UI/UX 기준과 원문 변경

기준은 사용자 제공 2025.08 KRDS PDF이다. 번호 문장 725개는 추출 후보, 구조 103개와 상호작용 52쪽은 대조 범위이며 공식 전체 기준 수가 아니다. 원문 그림의 등급을 추출 데이터로 추정하지 않는다.

회사 브랜드 FlowCore를 사용한다. 공식 배너/운영기관 식별자는 비정부 사이트에서 사용하지 않는 원문 PDF 225·231쪽을 따른다. 변경표 227/246/998쪽은 섹션 시작이고 실제 세부 변경은 229~231/249/1007쪽이다. 푸터에는 정확한 ‘개인정보 처리방침’ 링크를 시각적으로 구분한다. 복수 로그인 배치 권장은 단일 인증 샘플에서 조건부이다.

본문 기본 17px, 최소 16px, 행간 1.5 이상, 주요 대상 44px/모바일48px 회사 목표를 토큰에서 관리한다. 서체는 설치된 한국어 시스템 서체를 사용한다. Pretendard GOV를 패키지에 포함하지 않으면 사용했다고 표시하지 않는다. 제공 지시문의 104/106쪽은 두께/Vertical Trim이며 본문 크기 관련 원문 위치는 별도로 확인한다. 124쪽 행간, 123쪽 선명한 화면 역할별 15/7/4.5 목표, 204쪽 일반 최소/권장을 구분한다.

제목/현재위치/일관된 탐색, 영구 레이블/오류 요약, 단계별 검토·뒤로입력보존, 상태·빈결과·실패·처리중 안내를 제공한다. 컴포넌트 갤러리로 오류/비활성/초점/로딩 상태를 검토한다. 표준 자료실은 필터·개별 복사·선택결과 CSV/JSON/Markdown·전체 보고서 다운로드를 제공한다.

툴팁 652쪽 07·08 빈 항목을 생성하지 않으며 09는 원문 이상으로 유지한다. 온라인 KRDS는 참고 비교용이고 제공 판본의 조항을 임의 교체하지 않는다. 파일 제한은 704쪽 사용성 방향과 보안상 필요한 형식/개수/용량 제한의 회사 설계 선택을 구분한다.
