# 출처와 미확인 사항

기계 판독 원장은 `standards/source-gaps.json`, 원본 해시는 `standards/source-manifest.json`이다. 원본 Excel/PPT의 ‘계획’ 상태를 구현 결과로 전용하지 않는다.

원본 PDF 1181쪽과 변경표2쪽을 전문 추출했다. 725번호 후보의 텍스트 대조는 `evidence/source/candidate-audit.json`에 기록한다. 103구조와52상호작용쪽을 모두 보존하지만 원문 그림의 등급/예외와 모든 페이지의 시각 검토는 미완료다. 선택 대조쪽 123/249/1007은 원문 렌더를 확인했다. 104쪽은 글자두께,106쪽은 Vertical Trim으로 지시문의 크기 근거표현과 차이가 있어 판본/문맥을 재확인해야 한다.

사용자가 제시한 OA-9422는 [국방데이터 코드설계표준](https://www.data.go.kr/data/15083221/fileData.do?recommendDataYn=Y)의 공식 연결 URL이다. 국방 메타데이터 관리시스템(MDR: Meta Data Registry)의 정식 명칭을 공식 용어정의로 식별했다. 목록 판본은20260428이며 원사이트는HTTP400이므로 원본 CSV·해당 사업의 적용성이 확인되지 않았다. 기존 MDR-000을 확인필요로 유지하되 ‘이름 미확정’ 대신 ‘세부 적용 확인필요’로 갱신했다. MISRA/EU MDR로 치환하지 않는다. 목록성코드의 길이와 코드값관리의 코드·코드명 통제를 혼동하지 않는다.

현재 온라인 [KRDS 툴팁](https://www.krds.go.kr/html/site/component/component_08_05.html)은 마지막 혼용금지 표현이 PDF652쪽과 다르다. 빈07·08을 추정 복원하지 않는다. 2025.08 PDF 기준을 보존하고 최신 온라인 내용을 별도 비교대상으로 둔다.

현행 법령은 [국가법령정보센터 디지털포용법 시행령](https://www.law.go.kr/LSW/lsRvsDocListP.do?chrClsCd=010202&lsId=015019&lsRvsGubun=all)에서2026-01-22 시행을 조회했다. 사업 적용 여부는 대상기관·계약·법령 조항을 별도로 검토해야 한다. 블로그 본문,유료 규칙 전문,원문 미확인 등급을 생성하지 않는다.
