# ADR-0001 기본 스택과 검증의 분리

2026-10-20. 신규 저장소이므로 지시문의 React/TypeScript/.NET10/EF Core/SQLite 기본안을 채택한다. 로컬 .NET SDK를 설치하며 글로벌 시스템을 바꾸지 않는다. API8001과 Vite8000 프록시를 사용하고 배포는 동일출처 구조로 준비한다. 외부 공개 배포는 수행하지 않는다.

제공 PDF는 `references/`가 아닌 루트에 있었다. 원본 바이트를 references로 복사하고 SHA256로 식별한다. 초기 Excel/PPT는 적용계획이므로 실행 증빙으로 사용하지 않는다.

표준 정의/적용기록/시험/증빙을 분리한다. 자동검사 PASS는 실행된 검사의 결과일 뿐 각 외부표준 전체 PASS가 아니다. 원문 등급·검토자·화면낭독기 결과를 자동 생성하지 않는다. MDR은 정식 명칭 확인 전 보류한다.
