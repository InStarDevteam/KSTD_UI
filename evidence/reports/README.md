# 최종 보고서 검수 기록

이 폴더는 최종 Excel·PPTX·HTML 산출물의 생성·구조·수식·렌더·실제 브라우저 검사 기록입니다. 표준별 종합 PASS를 추가하는 실행기록이 아니며, `evidence/index.json`의 실제 자동시험과 캡처 기록을 대체하지 않습니다.

Excel 6개 시트와 PPT 18개 장표를 렌더링하고 확인했습니다. Excel 편집 fixture는 증빙 누락·수동 미실행·검토자/검토일 누락·편차·분모 0을 검사합니다. HTML은 실제 Chromium에서 검색·클립보드·다운로드·320px·CSP·axe를 확인했습니다. Microsoft Excel/PowerPoint 앱 자체와 실제 화면낭독기 검사는 미실행입니다.

검수 대상 파일의 SHA256은 `reports/DELIVERABLES.json`에 있습니다. PPT 구조검사 기록의 private 임시 경로는 생성 당시 경로이며, 최종 전달본은 `reports/Company_SW_Standards_Application_Report.pptx`입니다.
