# 상용 정적분석 연계 지점

현재 상용 도구 실행 실적은 없다. 사용 권한과 제품/버전/언어 프로파일/지원규칙 목록을 확보한 뒤 실제 도구로 저장소 `apps/api`, `apps/web/src`, `packages/ui`를 분석한다. 생성코드·외부라이브러리 제외와 취약점·라이선스 관리 범위를 혼동하지 않는다.

도구 원시결과는 `evidence/<run-id>/commercial/`에 보존한다. 실행 명령·도구버전·환경·종료코드·commit·입력해시·결과해시·지원규칙·미지원규칙·실제 사용경로·오탐 근거·검토자를 기록한다. SARIF 지원 제품은 SARIF와 원시 로그를 함께 보관한다. `scripts/evidence-lib.mjs`의 `recordArtifact`는 이미 실행한 결과파일을 원장으로 연결하는 진입점이다. 도구를 실행하지 않은 채 해당 함수를 호출해 검사실적을 만들지 않는다.

MDR은 국방 메타데이터 관리시스템이므로 C#/TS에 MISRA 규칙을 직접 적용하는 프로파일로 대신하지 않는다. 제품 코드에 없는 언어를 준수했다고 표시하지 않는다.
